# Curated learning profiles v1

Authored for the Phase 2 implementation and proposed for maintainer review. These are normative learning profiles, not empirical hiring requirements, employer statements, or independent expert consensus. CORE means central to this profile; EXPECTED means supporting; OPTIONAL means enrichment. No claim about job eligibility or readiness follows. Topic-to-skill mappings are curator choices. Acceptance is an explicit local CLI action; no automated or LLM extraction pipeline publishes canonical data.
